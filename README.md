# IC-LAB-Final-Project-3DGS
RTL-based hardware accelerator for 3D Gaussian Splatting (3DGS), featuring parallel depth sorting, LUT-based arithmetic, pipelined rendering, and software–hardware co-verification. Designed in Verilog for real-time rendering experiments, supporting 128×128 resolution, up to 64 Gaussian primitives, and a target clock period of 5 ns.
